# Foundry Light Client

Лёгкий нативный macOS-клиент для [Foundry VTT](https://foundryvtt.com/). Вместо тяжёлого браузера или официального приложения — компактное окно на AppKit + WKWebView: список серверов, быстрое подключение и отдельное окно на каждую игру.

## Основные возможности

- **Список серверов** — сохраняйте серверы с названием и адресом, редактируйте и удаляйте их; данные хранятся в `~/Library/Application Support/FoundryLite/servers.json`.
- **Быстрое подключение** — достаточно ввести `host:30000`, `http://host` или полную ссылку; схема `http://` подставляется автоматически.
- **Нативный лаунчер** — список серверов построен на AppKit без веб-движка, запускается мгновенно.
- **Отдельное окно на сервер** — размер и положение окна запоминаются для каждого сервера; закрытие окна полностью освобождает веб-процесс и память.
- **Масштаб страницы** — `⌘ +` / `⌘ −` / `⌘ 0`, значение сохраняется отдельно для каждого сервера.
- **Полноэкранный режим** — `⌃⌘F`.
- **Звук без лишних кликов** — музыка и эффекты Foundry воспроизводятся без предварительного клика.
- **Аудио и видеосвязь** — поддержка камеры и микрофона для встроенной связи Foundry (с запросом разрешения).
- **Всплывающие окна** — `window.open` (например, вынесенный журнал чата) открывается в отдельном окне клиента.
- **Загрузка файлов** — файлы сохраняются в «Загрузки» без перезаписи существующих; выбор файлов для загрузки на сервер работает через стандартный диалог.
- **Внешние ссылки** — ссылки на другие сайты открываются в браузере по умолчанию.
- **Работа по `http`** — разрешены серверы без сертификата, в том числе в локальной сети.
- **Устойчивость** — при падении веб-процесса страница перезагружается; при ошибке подключения предлагается повторить попытку или вернуться к списку.
- **Названия серверов** — вводите своё имя и редактируйте его в списке; если имя не задано, в заголовке окна показывается название мира Foundry.
- **Обновления из GitHub** — при запуске приложение проверяет новую версию и предлагает обновиться; кнопка «Проверить обновления» есть в окне со списком серверов и в меню. Обновление скачивается, заменяет приложение и перезапускает его.
- **Перезагрузка** — `⌘R`, а также без кэша `⇧⌘R`; `⌘L` возвращает к списку серверов.

## Требования

- macOS 14 или новее
- Xcode / Swift 5.9+ (для сборки)

## Сборка

```bash
./build.sh
```

Скрипт собирает релизную версию, генерирует иконку и создаёт `Foundry Lite.app` рядом со скриптом (подпись ad-hoc). Запуск: `open "Foundry Lite.app"`.

## Установка

Скачайте `FoundryLite-<версия>.dmg` из [Releases](https://github.com/sevenwind/foundry-light-client/releases), перетащите **Foundry Lite** в «Программы». Приложение подписано ad-hoc: при первом запуске откройте его через контекстное меню → «Открыть».

## Выпуск обновления

```bash
VERSION=1.2 ./build.sh
ditto -c -k --keepParent "Foundry Lite.app" FoundryLite.zip   # его скачивает автообновление
gh release create v1.2 FoundryLite.zip FoundryLite-1.2.dmg --title "v1.2"
```

## Структура проекта

| Файл | Назначение |
| --- | --- |
| `Sources/FoundryLite/main.swift` | точка входа |
| `AppDelegate.swift` | жизненный цикл приложения, окна игр |
| `Launcher.swift` | окно со списком серверов |
| `GameWindow.swift` | окно игры на WKWebView, загрузки, popup-окна |
| `Updater.swift` | проверка и установка обновлений из GitHub Releases |
| `Store.swift` | модель сервера и хранение списка |
| `MainMenu.swift` | главное меню и горячие клавиши |
| `tools/make_icon.swift` | генерация иконки приложения |
